# Tic-Tac-Toe Game

A basic Tic-Tac-Toe game implemented using HTML, CSS, and JavaScript. Play against another person and enjoy a classic game in the browser!

## Features

- **Player vs Player**: Two players (Player X and Player O) can play on the same device.
- **Win Detection**: Detects when a player wins or if the game is a tie.
- **Reset Button**: Reset the game by clicking on the RESET button.

## Installation

No installation required! Simply download or clone this repository and open `index.html` in any web browser to start playing.

To clone this repository, use the following command:
```bash
git clone https://github.com/irfanhussain25/Tic-Tac-Toe-Game.git
```

## Usage
1. Open index.html in your browser.
2. Player X always starts the game.
3. Click on an empty cell to make a move.
4. The game will declare a winner or a tie once a win condition or full board is detected.
5. Use the Reset button to start a new game.

## Game Rules
- The game is played on a 3x3 grid.
- Players take turns marking a cell on the grid, with Player X going first.
- The first player to get 3 of their marks in a horizontal, vertical, or diagonal row wins the game.
- If all cells are filled and no player has 3 in a row, the game ends in a tie.

## Project Structure
```
Tic-Tac-Toe-Game/
├── index.html       # Main HTML file
├── style.css        # CSS for styling
└── script.js        # JavaScript logic
```
- index.html: The main file that contains the structure of the game.
- style.css: Adds visual styling to the game board and elements.
- script.js: Contains the game logic and player interactions.
